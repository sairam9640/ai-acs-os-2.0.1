## 1. Application Build Stages (Section 2)

| Stage | Portal / Domain | Core UI Screens & Modules |
|---|---|---|
| **Stage A** | Shared Design System | Universal 6 UI states, Button/Input/Table components, command progress bar |
| **Stage B** | Super Admin Console | Tenant manager, global MRR/ARR charts, feature flag toggle, system health |
| **Stage C** | Operator Portal | Unified dashboard, customer list, ONT inventory, NOC alerts radar |
| **Stage D** | Customer 360 | 10-tab flagship view (Identity, Services, ONT, Wi-Fi, Connected Devices, Fiber GIS trace, Optical, Tickets, Audit, AI) |
| **Stage E** | Fiber GIS Canvas | Vector map layers, customer-to-OLT trace, OTDR fault pin, topology editor |
| **Stage F** | Incidents & Support | Correlated incident feed, SLA risk table, ticket management workspace |
| **Stage G** | Technician Mobile | Priority work order queue, turn-by-turn navigation, optical measurement entry |
| **Stage H** | Customer Self-Service | Broadband health card, speedtest utility, Wi-Fi password manager, invoices |
| **Stage I** | AI Copilot | Structured diagnosis cards, likely cause hypotheses, human approval dialogs |
| **Stage J** | Reports & Alerts | Asynchronous report generator, notification center |
| **Stage K** | Hardening | Accessibility (WCAG 2.1 AA), responsive mobile grids, XSS/CORS defenses |
