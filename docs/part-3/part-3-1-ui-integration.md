## 1. Multi-Portal Unification (Section 13)

The user experience integrates 4 distinct role-scoped portals into a unified design system:
1. **Super Admin Platform Console:** Global tenancy oversight, MRR/ARR financial aggregations, operator provisioning.
2. **Operator Web App & Customer 360:** 10-tab subscriber view (Identity, Services, ONT Hardware, Wi-Fi RF, Connected Devices, Fiber Route Trace, Optical History, Tickets, Audit Log, AI Copilot).
3. **Technician Mobile Field App:** Work order priority queue, turn-by-turn GIS navigation, optical power logging, offline sync cache.
4. **Customer Self-Service App:** Realtime connection health, speedtest utility, Wi-Fi password updates, billing invoice downloads, WhatsApp AI support bot.
